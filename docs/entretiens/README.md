# Kit d'entretiens praticiens — Nafas

**Objectif** : avant le 9 octobre 2026, mener 5 à 8 entretiens de 25 minutes avec des psychologues et psychiatres au Maroc, puis décider de la suite le week-end du 10–11 octobre.

On ne cherche pas à « vendre » Nafas. On cherche à savoir **si le problème existe vraiment** pour eux, et **ce qui les inquiète**.

## Règles importantes

- **Aucune donnée de patient.** Si un praticien parle d'un cas réel, ne note ni nom, ni détail permettant de reconnaître la personne. Note seulement l'idée (« patients qui oublient ce qui s'est passé dans la semaine »).
- **Demander avant de prendre des notes**, et ne pas enregistrer l'audio sans accord explicite.
- **Montrer la démo comme une démo** : données fictives, rien d'envoyé, pas prête pour de vrais patients.
- **Ne pas promettre** de date de lancement, de conformité CNDP ni de sécurité.
- Les retours sur le contenu clinique (questions, seuils, messages de crise) vont dans le dossier `docs/relecture/`, pas directement dans le code.
