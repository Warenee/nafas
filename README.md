# Nafas

Prototype de suivi entre les séances : journal quotidien (humeur, anxiété, sommeil, traitement), questionnaires validés (PHQ-9, GAD-7, WHO-5), plan de sécurité et espace praticien.

**Démo uniquement.** Toutes les données affichées sont fictives. Les saisies restent dans le navigateur de la personne et ne sont envoyées nulle part. Ne pas utiliser avec de vrais patients : une version réelle nécessite une autorisation de la CNDP (loi 09-08) et un hébergement adapté aux données de santé.

Nafas n'est pas un service d'urgence. Au Maroc : SAMU 141 · Police 19 · 112 depuis un mobile.

Projet étudiant en psychologie, ESP Casablanca.
